# GBHPL Storefront

A lightweight storefront for Gid’s Beverages & Health Products Ltd. The current version is a frontend preview for the Ghana shop experience.

## Run locally

From this folder, run:

```sh
node serve.mjs
```

Then open <http://127.0.0.1:4187>.

## Preview notes

- Product information and listed prices are provisional and need GBHPL approval.
- Delivery is available across Ghana; delivery charges and timing still need confirmation.
- The bag lasts for the current browser tab only. Checkout details are not saved.
- The Mobile Money controls are demonstrations only. They do not send a payment request or create an order.
- No backend or database is connected.
